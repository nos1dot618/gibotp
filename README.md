## Getting Started
1. Create a Firebase project and add the `google-services.json` file to the `app/` directory.
2. Set up a development server by cloning [gotps](https://github.com/hyouteki/gotps) and running it with `go run main.go`.
3. Build and launch the application, and update the remote server IP in the app settings to point to the development server if necessary.
